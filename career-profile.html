04 Current stewardship portfolio · proposed operating model

Impact Circle: A One Harvard Stewardship Model

Connecting Purpose, Evidence, Impact, and Relationships. The circle is a continuous stewardship process: a report is one milestone, not the end of the relationship.

What it means

One Harvard provides a shared purpose for Advancement, academic partners, Finance and donor-facing teams. This proposed coordination model does not rely on formal leadership authority over other units; each authorized office retains its own decisions.

What changes

Rather than ending with a delivered report, each cycle captures feedback, follows through with the donor and uses what was learned to improve the next round.

Eight delivery-assurance controls · in the order they run

These controls run inside the four workstreams — PIMS operations, QA/QC, stress testing and data integrity, smoke tests, acceptance testing, security and handoff, value audit, and Lean Six Sigma.

Step 1 · weeks 1–22

Process improvement (Lean Six Sigma)

Project charter, SIPOC, value-stream map, control chart and control plan. Owner: Process improvement lead.

Process sigma level: baseline → +0.5σ Step 2 · weeks 1–3

PIMS operations & service requests

Request catalog, triage rules, SLA targets and a PIMS run-book. Owner: Operations lead.

Requests closed within SLA: ≥ 95% Step 3 · weeks 4–6

QA/QC

Quality plan, review checklists, defect-severity scale and defect log. Owner: QA lead.

Defects escaping to production: ≤ 5% of all defects Step 4 · weeks 8–13

Stress testing & data integrity

Load and volume test results; reconciliation to the system of record. Owner: Data engineer.

Control totals reconciled to source: 100% · 0 critical breaks Step 5 · weeks 14–17

Smoke tests & critical user journeys

CUJ list and a 10-minute smoke script run after every release or refresh. Owner: QA lead.

CUJs passing before each release: 100% Step 6 · weeks 14–16

Acceptance testing

Acceptance criteria, UAT scripts and a signed acceptance. Owner: Business owner.

UAT cases passed: ≥ 95% · 0 open critical Step 7 · weeks 18–20

Security, delivery & handoff

Access matrix, security sign-off, runbook, training and 30-day hypercare. Owner: Information security + program lead.

Access review complete · critical findings: 100% · 0 Step 8 · weeks 21–22

Value audit & decision usefulness

Benefits vs. baseline, decisions informed, user survey and an extend / fix / close decision. Owner: Executive sponsor.

Leaders rating outputs useful for decisions: ≥ 4 / 5
Decision rights: the Director of Analytics & Reporting coordinates planning, requirements, evidence and follow-through. Vice Provost for Academic Affairs and the offices that own finance, IT and security, HR and academic decisions retain their approval responsibilities.
